The steps of this one change, in dependency order. Paths are under `plugins/qsm-forge/` unless they
start with `lib/` of the root. Every step ends with `bun run validate`, `bun run lint`, `bun run
typecheck` and `bun test` green, and nothing is added beyond the ask. The proof runs on the
repository qsmark-labs/qsm-marketplace with issues titled `test: ...`, all closed at the end.

## 1. Measure what `gh` does

Owns: nothing in the tree; the answers go in design.md decisions 3 and 6. Blocked by: nothing.

- [ ] 1.1 Create a `test: parent` issue and a `test: child` issue by `gh issue create`, once with
      `--parent` and once with a label that does not exist; record whether the failing call left an
      issue behind
- [ ] 1.2 `gh issue list --search "-is:blocked -type:Epic"` with an issue whose blocker is closed;
      record whether the closed blocker still blocks
- [ ] 1.3 Close the test issues; edit the two decisions if reality differs
